# bloodbank.software — Promo Site

Official landing page for [BloodBank.software](https://bloodbank.software) — open source blood bank management software for hospitals, NGOs, and government blood banks.

## About

This repository hosts the coming-soon landing page at [bloodbank.software](https://bloodbank.software), served via GitHub Pages.

The full product repository will be available at [github.com/bloodbank-software/bloodbank](https://github.com/bloodbank-software/bloodbank) at launch.

## Tech

Plain HTML · Tailwind CSS CDN · GitHub Pages · Cloudflare DNS

## Product

**BloodBank.software** is a free, self-hosted blood bank management system built with:

- **Frontend** — Next.js
- **Backend** — NestJS
- **Database** — MongoDB
- **Proxy** — Nginx
- **License** — Elastic License 2.0

Built for hospitals, NGOs, and government blood banks in India and Africa.
